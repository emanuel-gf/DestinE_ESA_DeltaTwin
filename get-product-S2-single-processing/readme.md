## How to use

This folder implements the retrieve of an S2 image. It demands a stac_item.json file containing metadata of STAC catalog. 

### Test STAC QUERY locally. 

To test it locally, please run the following command:

Go to the folder holding main.py
```bash
cd STAC_data_query/models
```
Run 
```bash
python main.py your_cdse_key your_cdse_secret "B02,B03,B04"

```
